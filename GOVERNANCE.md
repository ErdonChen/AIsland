# Governance

AIsland Community Edition is currently maintained by Erdon Chen as a benevolent maintainer project.

The maintainer sets the roadmap, reviews contributions, manages releases, and makes final decisions on security, privacy, compatibility, licensing, and project scope. Community discussion happens through GitHub Issues and pull requests. Decisions that materially affect the public architecture or Community/Pro boundary should be recorded in repository documentation.

This repository contains the Apache-2.0 Community Edition. Future paid products may be developed separately under different terms. Existing Community features will not be retroactively removed solely to create a paid tier, and security fixes plus major compatibility fixes for those features remain available to Community users.

If project stewardship changes, the repository will document the new maintainers and decision process before the transition takes effect.
