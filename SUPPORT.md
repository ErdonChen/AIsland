# Support

## Supported platform

- Officially supported: Windows 11 x64.
- Compatible but not fully validated: Windows 10 x64.
- Experimental: Codex and WorkBuddy integration paths for agents running inside WSL.
- Not currently supported: Windows ARM64, native macOS, or native Linux builds.

## Getting help

Use [GitHub Issues](https://github.com/ErdonChen/AIsland/issues) for reproducible bugs and focused feature requests. Search existing Issues first and remove personal data, conversation content, credentials, local usernames, and private file paths before posting.

Community support is best effort and has no guaranteed response time. Hook integrations and vendor session formats may change outside AIsland's control.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md). Conduct concerns must follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
